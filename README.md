# Mako Production System

Tooling for rebuilding the Petowal Mining Company operation reporting from scratch:
an Excel phase the site team can run now, followed by a web application on Resolute servers.

## Quick start (Windows)

1. Save `Setup-MakoPS.ps1` anywhere on C:.
2. Run it:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Setup-MakoPS.ps1
   ```

   It creates `C:\MakoPS` with `01_Tools`, `02_Source\2026` and `03_Inspection`,
   writes the inspection tooling, copies the 2026 PMC workbooks from the X: drive
   as working copies, runs the audit and opens the report folder.

3. Share `C:\MakoPS\03_Inspection` (report plus JSON files) for review. It holds
   structure only: sheet names, links, formula counts, defined names, VBA procedure
   names. No production figures, no VBA source.

Re-run `C:\MakoPS\01_Tools\Invoke-XlInspect.ps1` at any time to refresh the audit.

## Repository layout

| Path | Purpose |
|---|---|
| `Setup-MakoPS.ps1` | Self-contained bootstrap. Generated by `tools/build_setup.py`, do not edit by hand. |
| `tools/xl_inspect.py` | Workbook structural audit. See `tools/README.md`. |
| `tools/Invoke-XlInspect.ps1` | PowerShell runner (UTF-8 with BOM). |
| `tools/build_setup.py` | Rebuilds `Setup-MakoPS.ps1` from the files in `tools/`. |
| `data/2026/` | Placeholder only. Workbooks stay on C: and X:, never in this public repository. |

This repository is public. Do not commit site data to it.
